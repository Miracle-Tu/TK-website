### 2.2 Navbar 详细规格

**组件名**: `Navbar`
**位置**: `position: fixed; top: 0; z-index: 50`
**初始状态**:
- 高度: 80px
- 背景: transparent
- 无下边框

**滚动后状态** (滚动超过 100px):
- 高度: 60px
- 背景: `rgba(var(--bg-rgb), 0.85)` + `backdrop-filter: blur(12px)`
- 下边框: `1px solid var(--rule)`

**内容布局** (Flex, space-between):
```
+----------------------------------------------------------+
| [Logo]        [首页] [关于我] [工作经历] [项目] [方法论] [博客] [联系]  [🌙] |
+----------------------------------------------------------+
```

**Logo**: "TQ" 文字 Logo，font-weight 700，color: var(--ink)，hover → var(--accent)
**导航链接**: font-size 0.9rem，color: var(--ink)，hover → var(--accent)，当前页面下方有 2px accent 色底线
**主题切换按钮**: 右侧，太阳/月亮图标，20px
**移动端** (< 768px): 导航链接隐藏，显示汉堡菜单按钮，点击后全屏菜单展开

### 3.3 影响力看板 (ImpactBoard)

**组件名**: `ImpactBoard`
**布局**: Grid, 5列 (桌面), 3列 (平板), 2列 (手机，最后一项独占)
**间距**: `gap: 1.5rem`

**数据卡片结构** (每个):
```
+------------------+
|                  |
|     2.2rem       |  ← 数字，accent色，font-mono
|     5000w+       |
|                  |
|   累计管理资金    |  ← 标签，0.8rem，muted色
|                  |
+------------------+
```

**数据定义** (存储于 `app/data/metrics.ts`):
```typescript
export const metrics = [
  { value: '5000w+', label: '累计管理资金', suffix: '' },
  { value: '33+', label: '交付项目数', suffix: '' },
  { value: '800+', label: '峰值团队规模', suffix: '人' },
  { value: '5', label: '跨行业经验', suffix: '个行业' },
  { value: '2', label: '专业认证', suffix: '项' },
];
```

**入场动画**:
- 数字计数动画: 从 0 滚动到目标值，持续 1.5s，ease-out
- 卡片 stagger 入场: 间隔 0.1s
- 使用 `IntersectionObserver` 触发动画（仅触发一次）

## 10. 交互状态机

### 10.1 主题切换状态机

```
State: LightTheme
  document.dataset.theme = 'light'
  localStorage.theme = 'light'
  icon = Sun
  → Click toggle → State: DarkTheme

State: DarkTheme
  document.dataset.theme = 'dark'
  localStorage.theme = 'dark'
  icon = Moon
  → Click toggle → State: LightTheme

On page load:
  if localStorage.theme exists:
    apply stored theme
  else if prefers-color-scheme: dark:
    apply dark theme
  else:
    apply light theme
```

### 10.2 移动端菜单状态机

```
State: MenuClosed
  navbar links hidden
  hamburger icon visible
  overlay hidden
  body scroll: auto
  → Click hamburger → State: MenuOpening
    → overlay opacity 0→1 (0.3s)
    → menu slide in from right (0.3s)
    → State: MenuOpen

State: MenuOpen
  navbar links visible in overlay
  close icon visible
  overlay visible
  body scroll: locked
  → Click close OR Click overlay OR Click link → State: MenuClosing
    → overlay opacity 1→0 (0.2s)
    → menu slide out to right (0.2s)
    → State: MenuClosed
```

### 10.3 时间线展开状态机

```
State: AllCollapsed
  all items show header only
  → Click ItemA.expand → State: ItemAExpanded
    → ItemA content animates in
    → ItemA arrow rotates 180°

State: ItemAExpanded
  ItemA shows full content
  → Click ItemB.expand → State: ItemBExpanding
    → ItemA content animates out
    → ItemA arrow rotates back
    → ItemB content animates in
    → ItemB arrow rotates 180°
    → State: ItemBExpanded

  → Click ItemA.collapse → State: AllCollapsed
    → ItemA content animates out
    → ItemA arrow rotates back
```

### 10.4 项目筛选状态机

```
State: ShowingAll
  all project cards visible
  filter button "all" is active
  → Click Filter(category) → State: Filtering
    → non-matching cards: opacity→0, scale→0.95 (0.2s)
    → matching cards: reposition via grid (0.2s)
    → after animation, non-matching cards: display:none
    → State: Filtered(category)

State: Filtered(category)
  only matching cards visible
  corresponding filter button is active
  → Click Filter(all) → State: ShowingAll
    → all cards: display:block
    → all cards: opacity 0→1, scale 0.95→1 (0.2s)
  → Click Filter(otherCategory) → State: Filtering (same as above)
```

### 10.5 表单提交状态机

```
State: Idle
  form fields editable
  submit button: "发送消息", enabled
  → Click submit → State: Validating
    → if validation fails → State: ValidationError
      → show field-specific error messages
      → focus first invalid field
      → after 3s OR on input change → State: Idle
    → if validation passes → State: Submitting
      → submit button: "发送中...", disabled, spinner
      → POST /api/contact
      → if success → State: Success
        → form fades out
        → success message fades in
      → if error → State: SubmitError
        → submit button: "发送消息", enabled
        → show error banner
        → after 5s → State: Idle
```

### 10.6 滚动触发动画状态机

```
State: Hidden
  element: opacity 0, translateY(24px)
  → IntersectionObserver triggers (threshold 0.2)
    → element: opacity→1, translateY→0 (0.5s ease)
    → State: Visible

State: Visible
  element: opacity 1, translateY 0
  → no further transitions (one-shot)
```

### 10.7 页面转场动画

**页面切换** (Next.js App Router):
```
Exit: current page → opacity 1→0 (0.15s)
Enter: new page → opacity 0→1, translateY(10px)→0 (0.3s)
```

**实现方式**: 使用 Next.js `template.tsx` + CSS transitions，或 `framer-motion` 的 `AnimatePresence`。
